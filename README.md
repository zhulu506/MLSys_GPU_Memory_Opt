# MLSys_GPU_Memory_Opt

——显存突围：深度学习模型训练的 GPU 内存优化之旅

# 20250310 第 1 次提交

系统梳理本人读研期间阅读过的高水平论文及本人学位论文的参考文献。

其中，学位论文包括硕士论文和博士论文，文件名命名格式为：

```text
[年份]_[学位类型]_[学校]_[作者]_[论文标题].pdf

示例：  
📂 学位论文  
└── 2019_硕士_电科大_叶锦棉_资源受限下的神经网络模型训练问题.pdf
```

电子书，文件名命名格式为：

```text
[年份]_[电子书标题]_[标题翻译].pdf

示例：  
📂 电子书  
└── 2023_Operating Systems: Three Easy Pieces_操作系统导论.pdf
```

会议期刊论文，文件名命名格式为：

```text
[年份]_[会刊缩写]_[会刊等级/版本]_[论文标题].pdf

示例：  
📂 会议期刊论文
└── 2024_ASPLOS_A会_GMLake: Efficient and Transparent GPU Memory Defragmentation for Large-scale DNN Training with Virtual Memory Stitching.pdf
```

表格 InfoSummary.xlsx 中提供论文地址的论文均是 open access 的。但因笔者精力有限，可能遗漏了部分论文的地址，读者可以自行搜索下载。

表格 InfoSummary.xlsx 中的论文引用量为 2025 年 3 月 10 日的最新数据。论文引用量只能作为一个客观的评价指标，并不能完全代表论文质量。为了方便，笔者只使用 Google 学术提供的数据，未参考 arXiv 上的引用量数据。
